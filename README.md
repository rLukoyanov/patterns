# Паттерны

> [!NOTE]
> Паттерн проектирования — это типовое (проверенное) решение часто встречающейся проблемы в проектировании программного обеспечения.

> Важно: это не готовый код, а идея или шаблон того, как организовать код.

# 📌 Главное свойство паттерна

У паттерна есть три характеристики:

1️⃣ Повторяемость

2️⃣ узнаваемая структура

3️⃣ предсказуемость

# 📚 Что внутри репозитория

Сейчас репозиторий содержит **порождающие паттерны (Creational)**.

## Creational

- [Abstract Factory](Creational/Abstract%20Factory.md) — создание семейств связанных объектов.
- [Builder](Creational/Builder.md) — пошаговая сборка сложного объекта.
- [Factory Method](Creational/Factory%20Method.md) — делегирование создания объектов фабрике.
- [Prototype](Creational/Prototype.md) — создание через копирование готового объекта.
- [Singleton](Creational/Singleton.md) — единственный экземпляр с глобальной точкой доступа.

3. Структура
